How to use this app

  1. Programme Logic & Flow: The application operates sequentially from top to bottom, moving from order configuration and item selection to payment allocation, automated QR generation, and final action execution (WhatsApp or download).
  2. Expected Input:
    • Order Date and Order Number at the top bar.
    • Customer name (up to 20 characters) and a 13-digit mobile number layout.
    • Item descriptions, quantities, free quantities, and rates selected via interactive modals or custom entry.
    • Optional discount labeling and amount.
    • Split payment method allocation matching the exact order total.
  3. Resulting Output:
    • A real-time visual receipt summary with localized words formatting, dynamic customer appreciation quotes, and auto-generated UPI QR code grids for non-cash transfers.
    • Fully formatted WhatsApp messages or downloadable, high-resolution PNG order summaries.
  4. Further Actions:
    • Review payment status validation cues (unallocated or over-allocated warnings).
    • Use WA Pay or WA Image to dispatch details directly via WhatsApp, or click Save Order to download the receipt image locally.
